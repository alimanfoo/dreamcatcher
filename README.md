# dreamcatcher

dreamcatcher watches a GitHub repository for labelled issues, dispatches agents
for issue conversations and coding assignments, and carries each assignment to a
pull request for you to review and merge.

Read the documentation at <https://alimanfoo.github.io/dreamcatcher/>. It starts
with installation and a tutorial that takes one issue to a pull request, and it
holds the guides, the command and configuration references, and the agent-facing
contract.

## Contributing

Start with the [agent guide](AGENTS.md) for the development setup, project
conventions and required checks. [Testing](docs/testing.md) explains what the
test suite and CI establish, and [Releasing](docs/releasing.md) lists what to do
before each release.
